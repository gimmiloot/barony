# Баронство — браузерный пилот

[**Играть в браузере**](https://gimmiloot.github.io/barony/)

Текстовая стратегия о семье правителя и развитии небольшого владения. Пилот охватывает семь игровых лет: восстановление хозяйства, местные события, передачу власти наследнику и первое исполнение королевской подати.

В этом репозитории находится готовая браузерная сборка с настольной и мобильной компоновкой.

## Как играть

Откройте сайт GitHub Pages этого репозитория и нажмите **«Начать игру»**. Первый запуск загружает около 57 МБ до сжатия. Нужен современный браузер с поддержкой WebAssembly и WebGL 2. На компьютере удобно окно от 1280×720; на телефоне разделы выбираются списком сверху, а «Меню» содержит сохранение и загрузку. Длинные страницы прокручиваются вертикально. Удобнее читать в вертикальном положении; поворот поддерживается. Компоновка проверена на мобильных размерах в Chromium, физические телефоны ещё требуют проверки.

Новая партия длится **28 сезонов**. Подать короне — **24 золота ежегодно**, первый сбор осенью седьмого года. Для нового содержания начните новую историю: прежние сохранения сохраняют свой календарь и длительность.

Музыка запускается после первого взаимодействия со страницей. Её громкость можно изменить в настройках игры.

## Сохранения

Сохраняйте партию через **«Меню → Сохранить»**. Она хранится в браузере на этом устройстве. Очистка данных сайта может удалить её; между браузерами и устройствами партия автоматически не переносится.

В меню **«Загрузить»** можно скачать текущую партию в JSON и загрузить её из файла. После импорта нажмите **«Сохранить»**, чтобы продолжить с этого места при следующем запуске.
