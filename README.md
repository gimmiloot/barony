# Баронство — браузерный пилот

[**Играть в браузере**](https://gimmiloot.github.io/barony/)

Текстовая стратегия о семье правителя и развитии небольшого владения. Пилот охватывает шесть игровых лет: восстановление хозяйства, местные события и передачу власти наследнику.

В этом репозитории находится готовая браузерная сборка для компьютера.

## Как играть

Откройте сайт GitHub Pages этого репозитория и нажмите **«Начать игру»**. Первый запуск загружает около 56 МБ до сжатия. Нужен современный браузер с поддержкой WebAssembly и WebGL 2; рекомендуется окно не меньше 1280×720. Интерфейс для телефона пока не подготовлен.

Музыка запускается после первого взаимодействия со страницей. Её громкость можно изменить в настройках игры.

## Сохранения

Сохраняйте партию кнопкой **«Сохранить»**. Она хранится в браузере на этом устройстве. Очистка данных сайта может удалить её; между браузерами и устройствами партия автоматически не переносится.

В меню **«Загрузить»** можно скачать текущую партию в JSON и загрузить её из файла. После импорта нажмите **«Сохранить»**, чтобы продолжить с этого места при следующем запуске.
